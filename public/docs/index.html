Architecture & Core Engine

WebGL Native Unity 3D C# Godot 4 Node.js Zero Server Cost
Looking for class properties and methods?

Mereb is an ultra-lightweight (13 kB gzipped), zero-cost multiplayer netcode and matchmaking engine designed specifically for modern web games, web game portals (Poki, CrazyGames), mobile web browsers, indie game engines (Godot 4, Unity WebGL, Three.js, Phaser 3), and React applications.

The Economic Problem Mereb Solves
Dedicated server platforms (Hathora, AWS GameLift, Agones) cost $150 to $1,000+/month in continuous container uptime and bandwidth fees. For indie and web games monetizing via ad impressions ($1.50-$3.00 CPM), dedicated server bills bankrupt games. Mereb streams 60Hz gameplay directly P2P over WebRTC UDP, reducing server bills to $0/month.

High-Level Network Topology

Mereb utilizes a Host-Authoritative WebRTC Mesh Topology coordinated by Cloudflare Workers and Durable Objects:

• Authoritative Physics               WebRTC DataChannel   • Local Input Capture

• Damage & Collision Check                                 • Hermite Interpolation

Dual DataChannel Architecture

Unlike standard WebSockets that suffer from severe head-of-line blocking when a single packet drops on mobile Wi-Fi, Mereb initializes two independent WebRTC channels between peers:

Channel Protocol Reliability Use Case
unreliable UDP-like (SCTP) Ordered: false, MaxRetransmits: 0 60Hz entity transforms (x, y, z), rotations, health, aiming vectors, input streams.
reliable TCP-like (SCTP) Guaranteed Delivery Match start, player deaths, kills, round timers, game over, chat, and scoring.

Smart Bot Fallback (Eradicating Empty Lobbies)

If matchmaking exceeds botTimeoutMs (default: 8,000ms), Mereb automatically activates a local offline AI bot. The queue never feels empty, and players never bounce from your game.

5-Minute Quickstart

Setup Guide ESM / npm

Follow these steps to integrate real-time P2P multiplayer into your game in under 5 minutes:

Step 1: Install Package

npm install mereb-netcode

Step 2: Core Game Loop Blueprint

JavaScript / TypeScript 
import { MerebClient, MerebLobby, SnapshotInterpolator } from 'mereb-netcode';

// 1. Initialize Multiplayer Client
const net = new MerebClient({
  host: 'mereb-signaling.dawitbaslyos.workers.dev',
  botTimeoutMs: 8000,
  autoJoinFromUrl: true
});

// 2. Attach Drop-in Arcade Lobby UI
const lobby = new MerebLobby(net, { title: '⚔️ ARENA WARRIORS' });

// 3. Set up Interpolation Buffer for Smooth Opponent Movement
const interpolator = new SnapshotInterpolator({ bufferTime: 80 });

// 4. Handle Match Lifecycle
net.on('match-start', ({ role, isHost, localId, peerId, isBot }) => {
  console.log(`Match Active! Role: ${role}, Opponent: ${peerId}`);

  if (isHost) {
    // Host: Run Authoritative Simulation Loop (20-60Hz)
    setInterval(() => {
      net.sendState({
        t: Date.now(),
        x: player.x,
        y: player.y,
        health: player.health
      });
    }, 50);
  } else {
    // Client: Stream Inputs to Host
    window.addEventListener('keydown', (e) => {
      net.sendInput({ key: e.key, down: true });
    });
  }
});

// 5. Client receives World State & feeds Interpolator
net.on('state', (serverState) => {
  interpolator.pushSnapshot(serverState.t, { opponent: serverState });
});

// 6. Render Loop (60/120 FPS)
function render() {
  requestAnimationFrame(render);
  if (!net.isHost) {
    const smooth = interpolator.getInterpolated();
    if (smooth.opponent) {
      opponentSprite.x = smooth.opponent.x;
      opponentSprite.y = smooth.opponent.y;
    }
  }
}
requestAnimationFrame(render);

STUN / TURN Relays & Polar Billing

NAT Traversal Monetization

Mereb pools redundant STUN servers and automatically falls back to TLS TURN over port 443 for players behind strict institutional firewalls.

RFC 5766 Dynamic HMAC TURN Relays

When connecting from university dorms or cellular data, fetch dynamic time-limited TURN credentials:

const res = await fetch('https://mereb-signaling.workers.dev/api/turn-credentials');
const { iceServers } = await res.json();

const net = new MerebClient({
  host: 'mereb-signaling.workers.dev',
  turnServers: iceServers
});

Unity 3D WebGL Integration

Unity 2022 / 2023 / Unity 6 C# WebGL Bridge

Integrate Mereb into Unity WebGL builds via a native JavaScript bridge plugin (MerebBridge.jslib) and a C# manager (MerebNetworkManager.cs).

Step 1: Create `Assets/Plugins/WebGL/MerebBridge.jslib`

MerebBridge.jslib 
mergeInto(LibraryManager.library, {
  Mereb_Init: function(hostStr, botTimeoutMs) {
    var host = UTF8ToString(hostStr);
    window.merebClient = new window.Mereb.MerebClient({
      host: host,
      botTimeoutMs: botTimeoutMs,
      autoJoinFromUrl: true
    });
    window.merebClient.on('match-start', function(data) {
      SendMessage('MerebNetworkManager', 'OnNativeMatchStarted', JSON.stringify(data));
    });
    window.merebClient.on('state', function(state) {
      SendMessage('MerebNetworkManager', 'OnNativeStateReceived', JSON.stringify(state));
    });
    window.merebClient.on('input', function(input) {
      SendMessage('MerebNetworkManager', 'OnNativeInputReceived', JSON.stringify(input));
    });
  },
  Mereb_QuickPlay: function() {
    if (window.merebClient) window.merebClient.quickPlay();
  },
  Mereb_SendState: function(stateJsonStr) {
    if (window.merebClient) window.merebClient.sendState(JSON.parse(UTF8ToString(stateJsonStr)));
  },
  Mereb_SendInput: function(inputJsonStr) {
    if (window.merebClient) window.merebClient.sendInput(JSON.parse(UTF8ToString(inputJsonStr)));
  }
});

Binary Packing & Interpolation

85% Bandwidth Reduction

Eliminate JSON overhead and GC micro-stutters by compiling game state down to 10-byte binary packets with defineSchema:

JavaScript
import { defineSchema } from 'mereb-netcode';

export const PlayerSchema = defineSchema({
  x: 'fixed16',        // 2 bytes: precision 100
  z: 'fixed16',        // 2 bytes
  angle: 'fixed16',    // 2 bytes: precision 1000
  health: 'uint8',     // 1 byte
  isFiring: 'boolean'  // 1 bit
});

// Host transmits packed binary ArrayBuffer:
net.sendBinary(PlayerSchema.encode({ x: 12.5, z: -8.4, angle: 1.57, health: 100, isFiring: true }));

// Client decodes in <0.02ms with zero allocations:
net.on('binary', (buffer) => {
  const state = PlayerSchema.decode(buffer);
});

Web Portal Hooks (Poki & CrazyGames)

Ad Freeze Prevention

When video ads play on Poki or CrazyGames, browsers throttle background timers. Mereb's PortalManager prevents WebRTC disconnects during ads:

// Auto-hooks official portal SDK
net.usePortal('poki', window.PokiSDK);

// Commercial break pause
async function showAd() {
  await net.portal.commercialBreak(); // Pauses netcode safely
  gameEngine.resume();
}
